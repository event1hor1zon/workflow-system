# 接口文档 - 企业工作流系统

## 概述

本文档记录企业工作流系统的所有API接口。

Base URL: `/api`

---

## 工单接口

### 创建工单
```
POST /api/orders
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "title": "某区域网络信号问题",
  "description": "用户反映某区域5G信号覆盖不足..."
}

Response:
{
  "id": "REQ-20260408-001",
  "title": "某区域网络信号问题",
  "description": "用户反映某区域5G信号覆盖不足...",
  "creator_id": "USR-001",
  "creator_name": "张三",
  "creator_county_id": "CTY-001",
  "creator_department_id": null,
  "status": "pending",
  "event_type": null,
  "current_handler_id": null,
  "current_county_id": "CTY-001",
  "current_department_id": null,
  "create_time": "2026-04-08T10:00:00Z"
}
```

Authorization: Bearer <token>

### 县级经办人分配部门
```
PATCH /api/orders/:id/assign
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "department_ids": ["DEPT-001", "DEPT-002"],
  "comment": "需要网络部和工建部协同处理"
}

Response:
{
  "success": true,
  "order": { ... }
}
```

### 三部门间流转
```
POST /api/orders/:id/transfer
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "to_department_id": "DEPT-002",
  "comment": "移交至客户响应中心"
}

Response:
{
  "success": true,
  "order": { ... }
}
```

### 部门负责人处理工单
```
PATCH /api/orders/:id/process
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "event_type": "critical",
  "comment": "涉及多部门协调，标记为重大事件"
}

Response:
{
  "success": true,
  "order": {
    "status": "pending_approval",
    "event_type": "critical"
  }
}
```

### 确认结束工单
```
PATCH /api/orders/:id/confirm
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "role": "creator",
  "comment": "确认问题已解决"
}

Response:
{
  "success": true,
  "order": {
    "status": "resolved",
    "creator_confirmed": true
  }
}
```

### 退回工单
```
PATCH /api/orders/:id/reject
Authorization: Bearer <token>
Content-Type: application/json

Body:
{
  "comment": "工单描述不清，需要补充信息"
}

Response:
{
  "success": true,
  "order": {
    "status": "rejected"
  }
}
```

## 数据类型定义

### 工单状态 (status)
| 状态 | 说明 |
|------|------|
| pending | 待处理（县级经办人） |
| processing | 处理中（已分配部门） |
| pending_approval | 待审批 |
| resolved | 已解决 |
| rejected | 已退回 |

### 事件类型 (event_type)
| 类型 | 说明 |
|------|------|
| normal | 普通事件 |
| urgent | 紧急事件 |
| critical | 重大事件（需双签） |

### 用户角色 (role)
| 角色 | 说明 |
|------|------|
| user | 普通员工 |
| county_handler | 县级经办人 |
| department_head | 部门负责人 |
| top_leader | 最高权限人 |
| admin | 管理员 |

### 操作类型 (action)
| 类型 | 说明 |
|------|------|
| create | 创建 |
| assign | 分配部门 |
| transfer | 部门流转 |
| process | 处理 |
| confirm | 确认 |
| reject | 退回 |
