# 企业工作流系统

> 椭圆形拓扑图可视化工作流管理系统

**版本**: v2.0.0
**技术栈**: Vue 3 + NestJS + PostgreSQL
**前端端口**: 8080
**后端端口**: 3000

---

## 项目介绍

企业工作流系统是一套完整的工单流转管理平台，支持：
- 椭圆形拓扑图可视化展示
- 语音输入创建工单
- 三部门互相流转
- 权限分级控制
- 重大事件双签审批

---

## 核心功能

### 1. 首页全景图
- 椭圆形拓扑图展示工作流
- 最上层：各旗县分公司
- 中间层：上级部门 + 三部门枢纽
- 节点状态：已完成(绿) / 进行中(橙) / 待处理(灰)

### 2. 工单流转
- 员工提交工单（文字/语音）
- 县级经办人选择流转部门
- 三部门（网络部/客户响应中心/工程建设部）可互相流转

### 3. 事件类型
- **普通/紧急**：发起人确认即可结束
- **重大**：发起人+最高领导双签结束

### 4. 权限分级
| 角色 | 可查看 | 可操作 |
|------|--------|--------|
| 员工 | 自己发起的工单 | 提交、确认结束 |
| 县级经办人 | 所属县的工单 | 修改流转部门、流转 |
| 部门负责人 | 部门的工单 | 处理、选择类型、流转 |
| 最高权限人 | **所有工单** | 审批重大事件 |
| 管理员 | 所有 | 系统管理 |

## 部署说明

### 一键部署

```bash
git clone https://github.com/event1hor1zon/workflow-system.git
cd workflow-system
chmod +x scripts/deploy.sh
sudo ./scripts/deploy.sh
```

### 手动部署

1. 安装依赖：Node.js 20、PostgreSQL、Nginx、PM2
2. 配置数据库
3. 部署后端：`cd backend && npm install && npm run build`
4. 部署前端：`npm run build`
5. 配置Nginx

## API 端点

| 模块 | 端点 | 方法 | 功能 |
|------|------|------|------|
| 认证 | /api/auth/login | POST | 登录 |
| 用户 | /api/users | GET | 用户列表 |
| 县级 | /api/counties | GET | 县级列表 |
| 部门 | /api/departments | GET | 部门列表 |
| 工单 | /api/orders | GET/POST | 工单列表/创建 |
| 工单 | /api/orders/:id | GET | 工单详情 |
| 工单 | /api/orders/:id/topology | GET | 拓扑图数据 |
| 工单 | /api/orders/:id/assign | PATCH | 分配部门 |
| 工单 | /api/orders/:id/transfer | POST | 三部门流转 |
| 工单 | /api/orders/:id/process | PATCH | 处理工单 |
| 工单 | /api/orders/:id/confirm | PATCH | 确认结束 |
